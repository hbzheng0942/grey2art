# Current workflow risks

Use this when choosing a production route or diagnosing a blocked task. The current package identity comes from `greybox.py --version` and `MANIFEST.json`. No item here grants paid authority.

| Risk | Required response | Boundary |
|---|---|---|
| Expanding before a complete native sample | Preserve all selected styles; finish the priority style's agreed complete sample and actual H4 before expanding production. Qualify the processing/interaction family actually needed. | Asset counts and isolated good meshes do not establish sample readiness. |
| Declared reviews mistaken for useful art | Inspect actual pixels, GLBs and native gameplay views/states. Keep pass/fail/unclear observations and unresolved critical conditions. | Integrity and review records cannot judge aesthetics or authenticate a human. |
| Repeated local repair consumes the project | Inspect first, route by the observed defect, reuse successful assets and count repair attempts/active effort across workers and methods. | A static Blender backend is not a universal repair pipeline. |
| Unknown charged task is repeated | Keep original ledgers, provider/account identity, task/recovery IDs and unresolved claims. Reconcile the original attempt before retry or switching routes. | A new run, prompt, H3 timestamp or API key does not prove the first attempt failed. |
| A local artifact or runtime dependency changes | Diagnose the exact affected path/hash and original task/version. Recover through the supported original-ledger route; revalidate affected dependents before production. | Do not delete claims, edit frozen ledgers or disable hashes to force progress. |
| Parallel work exceeds capacity or spending scope | Bind confirmed account pools; retain each authorized operation's costs and per-wallet ceiling. Present totals across selected scopes accurately. | The shared executor coordinates local capacity, not a new case-wide budget or multi-machine lock. |
| New host/provider is treated as production-qualified | Separate documented capability, installed adapter, connection, actual invocation, useful production and human acceptance. Use the first already-authorized representative result. | No extra paid capability probe or automatic provider/region fallback. |
| Remesh or animation breaks appearance/behavior | Preserve source identity and any needed texture baking; inspect silhouette/materials and recheck affected rig, contact, interfaces and native behavior. | A face-count target is not measured device performance; optional processing is not mandatory for suitable assets. |
| Upgrade invalidates a running task | Retain the bound package/interpreter and original recovery route. Plan an explicit affected migration before new production under changed runtime bytes. | Repinning context does not relabel old evidence or bypass frozen authorization. |
| Engine/carrier scopes are confused | Use the requested native endpoint. Godot/Unity playable delivery has gameplay checks; a pure Blender spatial delivery has editable source/views/dependencies and its actual acceptance. | Static Three.js audits and UE knowledge do not certify native play. |
| Feedback exposes private material | Export only relevant redacted observations and inspect the export before sharing. | No keys, signed URLs, original private approvals, full conversation or copied game tree. |

Real multistyle workload, same-asset multiview quality, current host/platform qualification, provider-specific useful output, character behavior and target-device performance require actual scoped observations. Measure success, elapsed time, accepted cost and human repair before claiming efficiency. [Current status](candidate-status.md) separates available mechanisms from that evidence.

Use [production control](production-control.md) for sample/family/repair scheduling, [execution](execution-contract.md) for shared local capacity and original attempts, [provider accounts](provider-accounts.md) for regional credential binding, and [continuity](continuity.md) for task recovery. Keep small source/hash-bound evidence beside the owning case; do not copy games, assets or engine binaries for review.
