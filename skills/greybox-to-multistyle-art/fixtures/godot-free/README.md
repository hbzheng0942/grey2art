# 免费 Godot 验证夹具

全部文件为本项目制作，可自由复制、修改。没有远程资产、凭据或生成费用。

这是技术接入夹具，不是美术质量示例：两个连通空间、一个共享地标、可移动方块和可收集物体。`A/D` 移动，`Space` 收集，`T` 切换空间。收集物上的美术子件必须随逻辑物隐藏；碰撞数量保持不变。

将此小目录复制到工作目录后使用技能入口创建运行。不要在只读安装目录里生成运行记录或 `.godot` 缓存。`plan.json` 提供两种免费程序化外观及 18 条状态断言；原生验证保存真实输入、状态及两空间截图。RGB 色块和 1 米标尺只作为可见校准探针，不代表已自动通过色彩精度或审美验收。`raw_probe.tscn` 是非中心 pivot、父子非均匀源变换和原始材质保留探针。

计划中的 `contract.scene` / `camera` 是实际节点路径，`bindings.owner` 指向玩法节点；`hide` 仅允许视觉节点。`uniform_scale` 为标量，`normalize` 从原始资源重新计算；导入模型默认保留材质。需要改变材质时单独声明 `material_override`。骨架与关节模型必须标注 `kind` 并使用明确锚点，不能按动画姿势做包围盒归一化。

`source.units` 可显式选 `m/cm/mm`，`source.basis` 可选 `godot/gltf/z_up`。Godot 已导入的标准 glTF 使用默认 `godot`，不要重复转轴或改成厘米。特殊 Z-up 来源通过父节点转轴，保留原始子层级。`source_anchor` 使用完成源转轴后的未缩放坐标。`normalize.max_extent` 是最终米制最大边长，自动包含单位换算，重复运行不会累积转换。动态加载路径无法从代码常量解析时，列入 `contract.source_paths` 以绑定验证证据。

已有工程如使用 `res://../` 或资源链接，可在 `contract.dependency_roots` 显式声明这些只读来源的根目录，例如 `['..']`。这些文件同样记录内容 hash；不能因此把输出或新资源写到工程外。只声明当前案例实际需要的根目录，不把整个用户目录当成依赖范围。

`normalize.space` 默认 `world`：最终最大边长包含逻辑父节点缩放与放置旋转；显式选择 `owner` 则使用父节点本地尺寸。原有父节点的非均匀形变仍然保留，不会为归一化改动玩法变换或骨架。包围盒底部锚点只表示外接盒接触；屋顶、坡面等实际支撑面必须另行测量，不能把模型最高点当成可支撑表面。程序化 box 的 size 是 XYZ 尺寸；sphere 的 size 是直径、高度、相同直径；cylinder 的 size 是顶面直径、高度、底面直径。

当前原生验证覆盖同根节点内的空间过渡，不代表任意 `change_scene_to_file` 场景切换、流式加载或复杂第三方脚本都已适配。
