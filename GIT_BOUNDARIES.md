# Repository boundary

This is the standalone `greybox-to-multistyle-art` source repository. Track the installable Skill, synthetic fixtures and tests, manifest, licenses, public documentation, curated showcase media and CI configuration.

Game projects and their resources remain independent. Do not recursively add, clean, archive or copy neighboring repositories. Original models, source screenshot collections, engines, caches, private ledgers, user decisions, credentials and provider recovery data remain in their owning projects. Curated images requested for the public documentation belong under `docs/demo/` with source identities; displaying them does not redistribute the source game assets.

Use incremental edits and Git commits for source checkpoints. Do not copy the repository or its `.git` directory to make a snapshot. Preserve existing histories and collaborators' uncommitted work. Cleanup of the current public tree does not authorize rewriting history, deleting private local evidence or changing another repository.

`main` is the development and delivery branch. Use normal fast-forward pushes; do not bypass server protections, move published tags or invent release facts. GitLab and GitHub publication are separate external actions.

The installable package contains only files declared by its manifest. Repository documentation and curated media are not installed with the Skill. Optional legacy adapters require their separately supplied external data; private historical case inputs are deliberately absent.
