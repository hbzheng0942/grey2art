## Submit a case / 提交案例

Follow the [contribution guide](../../CONTRIBUTING.md) or [中文贡献说明](../../CONTRIBUTING.zh-CN.md). Include the real greybox, at least two implemented art directions, matching native views or gameplay, source version, credit and display rights. A selected concept or pending input keeps its actual stage label.

提交真实灰盒、至少两个已实现美术方向、对应原生截图或玩法实录、源版本、署名和展示授权。选中的概念或待补输入继续标明实际阶段。[Media provenance / 媒体来源](../demo/PROVENANCE.md) records copied source bytes and rendering scope.
